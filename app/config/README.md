# 網站配置

這個資料夾集中放置網站內容設定。修改文字、Q&A 或終端機顯示的幹部名單時，優先修改這裡的檔案，不需要直接改 Vue 元件。

- `site.ts`：網站名稱、網站介紹、Logo 路徑、作者與原始碼連結。頁面 SEO 標題也會使用這裡的設定。
- `home.ts`：首頁桌面圖示、歡迎視窗與各創作組別的顯示文字。
- `qa.ts`：首頁 Q&A 項目。每一筆需要 `value`、`title`、`content`，內容中的 `\n` 會換行。
- `officers.ts`：終端機輸入 `member` 時顯示的社團幹部名單，可新增或刪除職位。
- `links.ts`：友情連結資料（目前仍放在既有設定檔中）。

Logo 檔案請放在 `public/`，並在 `site.ts` 的 `logo.src` 使用以 `/` 開頭的路徑，例如 `/ddc-logo.jpg`。修改後請重新啟動開發伺服器，確認首頁、關於頁、Q&A 與終端機內容都正常。
